# 最后的记忆酒馆

这是基于 `Steam Punk Bar` 模型制作的小空间叙事体验。酒馆建筑本身是一个“记忆容器”，玩家不是寻找道具，而是在倾听建筑部件里残留的情绪。

## 运行方式

1. 打开终端进入本文件夹：
   `C:\Users\23302\Desktop\gipuli`
2. 启动本地预览：
   `npm run dev -- --port 5197 --strictPort`
3. 浏览器打开：
   `http://127.0.0.1:5197`

## 已包含内容

- 永恒黄昏天空与远景森林
- 暖色灯光、体积感雾、漂浮粒子
- 蒸汽动画与缓慢转动的机械齿轮
- 柔和反射地面
- 深蓝黄昏风格开场叙事页面
- 点击“进入酒馆”后进入当前酒馆场景
- 鼠标悬停发光
- 点击物体显示故事文本
- 靠近酒桶时播放低频氛围音
- 点击钟表触发时间减慢
- 10 个建筑记忆交互点：酒桶、钟表、路灯、木桥、门牌、烟囱、窗户、桌子、凳子、门
- 重要物件触发短暂记忆幻影，例如模糊人影、温暖灯光、旧日人群残响
- 收集完成后中央核心点亮
- 幻想治愈游戏风格 UI
- 本地 MP3 背景音乐，文件名为 `music.mp3`
- 右下角“开启音乐/关闭音乐”按钮，首次点击后播放，循环播放，默认音量 0.35，带淡入淡出
- Three.js 基础几何体制作的极简暖白小人角色，约为酒馆模型总高的 1/10
- 角色脚下光环、边缘柔光、待机上下漂浮、移动前倾摆动、跳跃拖尾粒子
- WASD 移动、Shift 跑步、Space 跳跃、V 切换全局/第三人称视角、E 靠近互动
- 鼠标点击草地或建筑平台，人物会自动走向点击位置
- 基于酒馆模型网格生成的轻量碰撞：人物可站在底座平台上，并会被墙壁、凳子、桶和较高构件阻挡
- 故事碎片包含小纸片、瓶子、羽毛、钥匙等实体小物件，不再只是空中的光点
- 第三人称相机改为稳定跟随，使用 `cameraSmooth = 0.08` 控制平滑度
- 跳跃高度受限，屋顶/墙体顶部不再作为可行走落脚面，异常高度会自动回到安全地面
